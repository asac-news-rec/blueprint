# 뉴스 추천 공동 청사진

SKP AI DE 1기 개인화 뉴스 추천 팀의 영역별 청사진을 **HTML 파일 하나(`index.html`)**에 모았다. 내려받아 브라우저로 열면 된다. 인터넷 연결이 없어도 열린다(글꼴만 기본 글꼴로 보임).

대문에서 카드를 누르면 각 페이지로 이동하고, 브라우저 뒤로 가기도 동작한다.

| 페이지 | 내용 | 작성 |
|---|---|---|
| 대문 | 영역 카드와 데이터 흐름 | 공동 |
| 뉴스 생성·서비스 | 작성 예정 | 태원 |
| 프론트엔드·행동 수집 | 초안 v0.6 | 세호 |
| 처리·피처·모델 | 피처 정의서·DAG·CTR 모델 | 윤모 |
| 청사진 정리와 인프라 | 청사진 6단계·인프라 구성도·툴 카탈로그 | 장주현 |
| 작업 나열표 | 28개 (10/29 WBS 기준) | 장주현 |

담당과 내용은 팀 합의 전 초안이다.
