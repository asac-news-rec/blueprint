# 뉴스 추천 공동 청사진

SKP AI DE 1기 개인화 뉴스 추천 팀의 영역별 청사진을 모은 정적 HTML이다. `index.html`을 브라우저로 열면 된다.

| 파일 | 내용 | 작성 |
|---|---|---|
| index.html | 대문 | 공동 |
| taewon.html | 뉴스 생성·서비스 (작성 예정) | 태원 |
| seho.html | 프론트엔드·행동 수집 초안 v0.6 | 세호 |
| yunmo.html | 처리·피처·모델 | 윤모 |
| juhyun.html | 청사진 정리·인프라 구성도·툴 카탈로그 | 장주현 |
| wbs.html | 작업 나열표 28개 (10/29 WBS 기준) | 장주현 |

담당과 내용은 팀 합의 전 초안이다.
